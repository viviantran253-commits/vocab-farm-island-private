# Vocab Farm Island v0.7 — Input Fix & Vietnamese Plot Pricing

- Replaced the invisible one-pixel spelling input with one real, visible, focusable character input per blank, visually integrated into the word (no separated answer boxes).
- Desktop typing directly fills a blank and advances to the next blank. Mobile virtual-keyboard input does the same.
- Supports clicking an earlier blank to edit, arrow navigation, backspace, paste across blanks and Enter to submit completed words.
- Plot expansion now includes full Vietnamese explanations of the 15% price, its minimum price, and protected 16-gold reserve.
- Mirrored game and stylesheet changes in the Google Apps Script student app templates.
- No changes to student saves, teacher permissions, or private backend.

## Security / online status

Offline browser saves remain local. This code does not deploy Google Apps Script automatically. Teacher reports across devices work only after installing and authorizing the private backend.
